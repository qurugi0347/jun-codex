# 출력 최적화

반복 실행되는 지침과 자동화 출력은 컨텍스트를 계속 소비하므로 짧고 밀도 있게 작성한다.

## 권장 예산

| 출력 | 권장 | 최대 |
|------|------|------|
| 자동화 메시지 1개 | 50줄 | 80줄 |
| 한 작업의 보조 출력 합계 | 120줄 | 150줄 |
| 서브 에이전트 보고 | 30줄 | 50줄 |

## 축약 기법

| 기법 | Before | After |
|------|--------|-------|
| 표 사용 | 여러 문단 설명 | 1개 표 |
| 인라인 사용 | 긴 코드 블록 | `핵심 명령` |
| 키워드 사용 | "이 작업은 Git 담당..." | `Git 작업 -> Git skill` |
| 1줄 요약 | 배경 5줄 | 핵심 판단 1줄 |

## 삭제 대상

- 같은 내용을 두 번 이상 설명하는 문장
- 이미 상위 문서에 있는 규칙의 반복
- 행동보다 이유 설명이 긴 문단
- 긴 ASCII 다이어그램
- 예시가 3개 이상인 동일 규칙
