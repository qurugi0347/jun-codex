# 고급 프롬프트 모드

복잡한 기획, 검토, 조율 작업은 단일 응답보다 단계별 모드로 나누면 품질이 안정된다.

## Ultra Plan 패턴

사용 시점:

- 요구사항이 크고 불명확하다.
- DB/API/FE 등 여러 계층이 같이 바뀐다.
- 구현 전에 위험과 대안을 정리해야 한다.

흐름:

```text
목표 확인 -> 코드/문서 탐색 -> 설계 대안 작성 -> 위험 검토 -> 실행 체크리스트
```

출력:

- 목적과 비목적
- 현재 구현 맥락
- 설계 결정과 차선책
- 단계별 작업 목록
- 검증 계획

## Coordinator 패턴

사용 시점:

- 병렬 탐색이나 독립 검증이 필요하다.
- 서로 다른 영역의 결과를 합쳐야 한다.

흐름:

```text
작업 분리 -> 각 영역 조사 -> 결과 통합 -> 충돌 해결 -> 최종 실행안
```

규칙:

- 각 하위 작업의 입력과 기대 출력을 명확히 한다.
- 결과는 `Discoveries`, `Changes`, `Reasoning` 형태로 통합한다.
- 판단이 충돌하면 근거와 함께 사용자에게 확인한다.
