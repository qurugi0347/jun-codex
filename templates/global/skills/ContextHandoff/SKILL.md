# ContextHandoff

긴 대화나 큰 작업을 이어가기 어려울 때 `HANDOFF.md`에 핵심 상태만 남긴다.

## 사용 시점

- 컨텍스트가 길어져 응답 품질이 떨어진다.
- 작업을 새 세션에서 이어가야 한다.
- 실패한 시도와 다음 행동을 명확히 보존해야 한다.

## 작성 위치

프로젝트 루트에 `HANDOFF.md`를 만든다. 작업이 끝나면 삭제한다.

## 템플릿

```markdown
# 프로젝트: [이름]

## 목표
[현재 작업의 최종 목표]

## 완료된 작업
- [완료 항목]

## 시도했지만 실패한 것
- [실패 항목]: [실패 이유]

## 현재 문제
[지금 막혀있는 것]

## 다음 단계
1. [즉시 해야 할 것]
2. [그 다음 해야 할 것]
```

## 규칙

- 500자 안팎으로 작성한다.
- 실패한 시도를 반드시 포함한다.
- 코드 스니펫보다 파일 경로와 상태를 남긴다.
- 새 세션에서는 `HANDOFF.md`를 먼저 읽고 이어간다.
