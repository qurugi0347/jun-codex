# 긍정 표현

프롬프트는 금지 목록보다 원하는 행동을 직접 적을 때 안정적으로 동작한다.

| 약한 표현 | 좋은 표현 |
|-----------|-----------|
| 직접 수정하지 마라 | 모든 수정은 요청 범위 파일에만 적용한다 |
| Git 명령어 실행 금지 | Git 작업은 사용자가 요청한 범위에서만 수행한다 |
| 3개 이상 파일 수정 금지 | 파일 수정은 필요한 최소 파일로 제한한다 |
| 장황하게 쓰지 마라 | 핵심 판단과 결과만 간결하게 쓴다 |

## 작성 규칙

- 제약은 `~만 한다`, `~전담`, `~우선` 형태로 쓴다.
- 피해야 할 행동을 쓸 때는 대안 행동을 같이 적는다.
- 모호한 품질 표현보다 확인 가능한 행동을 적는다.
